# MediStock – Pharmacy Management System

MediStock is a web-based Pharmacy Management System designed to help manage medicines, stock, billing, customers, suppliers, and reports in one place.

## 🌐 Live Website

Visit the live MediStock website through GitHub Pages.

## 📌 Project Features

- 🔐 Login and Logout
- 💊 Medicine Management
- 📦 Stock Management
- 🧾 Billing System
- 👥 Customer Management
- 🚚 Supplier Management
- 📊 Reports and Summary
- ⚠️ Low Stock Detection
- 💰 Total Sales Tracking
- 📱 Responsive Design
- ✨ Interactive User Interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- VS Code
- GitHub Pages
- Local Storage

## 📂 Main Pages

- Dashboard
- Medicines
- Stock
- Billing
- Customers
- Suppliers
- Reports
- Login

## 🎯 Project Objective

The objective of MediStock is to provide a simple and user-friendly web application for managing pharmacy-related operations efficiently.

## 💾 Data Management

The application uses browser Local Storage to maintain medicine, customer, supplier, and sales data.
